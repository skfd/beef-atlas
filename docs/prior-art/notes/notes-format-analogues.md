# Notes: format analogues (atlas + daily game + affiliate)

Method caveat from agent: monetization read from text extracts; JS-injected ads may be invisible.
Each entry labelled fetched / index-only / blocked.

## Single-domain reference atlases
- **TasteAtlas** — https://www.tasteatlas.com — nearest conceptual prior art. ~10,000 dishes/drinks/
  ingredients + 9,000 restaurants mapped by place. Founded 2015 by Matija Babic. English only per
  Wikipedia. (Wikipedia fetched; site 403s to automated fetch.) A `/quiz` URL exists in the search
  index, unverified.
- **FishBase** — https://www.fishbase.se — 36,700 fish species, 333,200 common names, 100+ languages
  (fetched). Free, CC BY-NC. No game. Institution-funded.
- **VIVC (Vitis International Variety Catalogue)** — https://www.vivc.de — ~23,000 grape cultivars
  with cross-national **synonym / prime-name** tracking, links to FR/IT/ES/BG/AM national databases
  (fetched). Government research (Julius Kuhn-Institut), unmonetized. Structurally the closest thing
  to "the same object named differently in each country, done rigorously".
- **PepperScale Hot Pepper List** — https://pepperscale.com/hot-pepper-list/ — 176+ chillies,
  filterable by Scoville/species/origin/flavour (fetched). English only, no game.
  **Amazon Associates confirmed** (`tag=pepperscale-20`). Nearest match to carneatlas' business model.
- **Animated Knots by Grog** — https://www.animatedknots.com — knots by activity/type (fetched).
  English only. No game but a **"Knot of the Day"** daily hook. Monetized via paid iOS/Android apps
  and an advertising-contact page.
- **Plants For A Future** — https://pfaf.org — 8,000+ plants, edible/medicinal uses (fetched). UK
  charity: donations, own books, suppliers directory.
- cheese.com — connection refused from the agent's environment; not verified.

## Reference corpora that bolted on a daily game
- **OEC -> Tradle** — https://oec.world/en/games, https://games.oec.world/en/tradle/ (index-only,
  403s). Daily "guess the country from its export chart", built on the Observatory of Economic
  Complexity's trade data. Cleanest corpus-first example. HN: **476 points / 89 comments**.
- **Merriam-Webster -> Quordle** — dictionary publisher *acquired* a daily game (Jan 2023, terms
  undisclosed); president pledged no paywall (index-only).
- **Metazooa / Metaflora** — https://metazooa.com , https://flora.metazooa.com — daily guessing over
  a real taxonomy tree, by Trainwreck Labs (fetched). Game-only, no browsable corpus. No monetization
  found. HN: 107 and 88 points.
- **FoodGuessr** — https://www.foodguessr.com — daily 3-dish "guess the cuisine's country" (fetched).
  Standalone, still in development, no monetization visible.
- **Teuteuf Games** (Worldle, WhenTaken, GeoGrid) — standalone daily-game studio, 16+ titles, no
  reference corpus.

## Does corpus + daily game + affiliate work?
- **No public revenue figures found.**
- Teuteuf's CEO describes ads via a managed partner (Publisher Collective); no numbers disclosed.
- Merriam-Webster bought Quordle for an undisclosed sum, kept it free.
- **Spotify acquired Heardle (Jul 2022) and shut it down May 2023** — strongest negative signal that
  a bolted-on daily game does not automatically retain value for the corpus owner.
- HN front-page spikes (Tradle 476 pts) show the game drives bursts of *distribution*, not revenue.
